# Data

All datasets are public. Download the raw files into `data/raw/` as listed below,
then run `make data` to build `data/processed/<name>/{data.npz,meta.json}`.

| dataset | put here | source |
|---|---|---|
| METABRIC (subtype, ER, HER2, integrative cluster, grade, semi-synthetic) | `data/raw/brca_metabric/` (the extracted study folder, with `data_clinical_patient.txt`, `data_mrna_illumina_microarray.txt`, ...) | cBioPortal study `brca_metabric`: https://www.cbioportal.org/study/summary?id=brca_metabric (also in https://github.com/cBioPortal/datahub/tree/master/public/brca_metabric). License: ODbL 1.0. |
| TCGA breast RNA-seq | `data/raw/tcga_brca/HiSeqV2.gz`, `data/raw/tcga_brca/BRCA_clinicalMatrix` | UCSC Xena: https://tcga.xenahubs.net/download/TCGA.BRCA.sampleMap/HiSeqV2.gz and https://tcga.xenahubs.net/download/TCGA.BRCA.sampleMap/BRCA_clinicalMatrix |
| TCGA diffuse glioma (GBM+LGG) | `data/raw/tcga_GBMLGG/HiSeqV2.gz`, `data/raw/tcga_subtypes/TCGASubtype.20170308.tsv.gz` | https://tcga.xenahubs.net/download/TCGA.GBMLGG.sampleMap/HiSeqV2.gz and https://pancanatlas.xenahubs.net/download/TCGASubtype.20170308.tsv.gz |
| UCI gene expression cancer RNA-Seq | `data/raw/uci_rnaseq.zip` (rename the download) | https://archive.ics.uci.edu/static/public/401/gene+expression+cancer+rna+seq.zip (CC BY 4.0) |
| UCI Human Activity Recognition Using Smartphones | `data/raw/uci_tabular/har.zip` (rename the download) | https://archive.ics.uci.edu/static/public/240/human+activity+recognition+using+smartphones.zip (CC BY 4.0) |
| WDBC | nothing to download | bundled with scikit-learn |
| synthetic structural causal model | nothing to download | generated by the code |

The optional UCI datasets used only in the screen that selected the activity data
(`uci_optdigits`, `uci_satimage`, `uci_mfeat`) are read from
`data/raw/uci_tabular/{optdigits,satimage,mfeat}.zip`.

Every dataset is reduced to the 200 features with the highest variance (1,000 for
`metabric1000`), ranked on all rows without using labels; see the files in
`configs/datasets/`.
